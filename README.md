# India Daily Trend Briefings

Auto-generated daily briefings on what's trending in India — tech & AI, markets, politics, Bangalore/Chennai/Mumbai, sports, entertainment, crime, health, international.

Generated by a [Hermes Agent](https://hermes.nousresearch.com) cron job at 09:00 IST every day, with a host-boot catch-up trigger so missed runs replay when the laptop wakes up.

## Files per day

| File | Purpose |
|------|---------|
| `YYYY-MM-DD.md` | Human-readable Telegram digest (the message you would receive). |
| `YYYY-MM-DD.json` | Structured payload: ranked trends with sources, categories, confidence scores. |
| `YYYY-MM-DD.html` | Self-contained styled HTML page for browser viewing. |
| `history/YYYY-MM-DD.json` | Run metadata: generated_at, totals (raw/kept/sources/categories), validation status, delivery channel. |

The `.md` is the canonical digest. The `.json` is the source of truth if you want to query trends over time. The `.html` is for sharing a link.

## Why a public repo?

The Telegram delivery channel was flaky (token-env-var redaction issue). GitHub gives us:

- A durable, linkable, browsable history independent of any chat platform.
- A second delivery channel: anyone with the link can read today's briefing.
- A natural audit trail — every push is a commit, every day is a diff.

## Provenance

Every daily file is generated by `india-trend-briefing` skill running as a scheduled Hermes Agent job. The generator commits and pushes at the end of each run as part of the success path. If a day is missing, either the job failed (check the watcher) or the push failed (check `last_delivery_error`).
